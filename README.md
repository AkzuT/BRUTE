# BRUTE

BRUTE is an authentication and authorization system designed around identity, profile, and credential separation to minimize attack surface and protect against account takeover vectors.

## Stack | BRUTE — API

- **Runtime:** Node.js v22.19.0
- **Framework:** NestJS v11.0.24
- **Language:** TypeScript v5.9.3
- **ORM:** TypeORM v0.3.31
- **Database:** SQL Server Express Edition

## Stack | BRUTE — Frontend

- **Runtime:** Node.js 22.19.0
- **Framework:** Vite v8.1.1 — React v19.1.1
- **Language:** TypeScript v6.0.2

## Structure

- `brute/brute-api` — API
- `brute/brute-db` — Database
- `brute/brute-docs` — Documentation
- `brute/brute-web` — Frontend
